## Projects Highlighted

### 🎮 Hydro Rush

A fast-paced iOS arcade game built with Swift and SpriteKit. Players dodge bombs, collect fish for bonus points, and grab score-multiplying flags. Features a coin currency system, particle effects, sound design, and persistent high scores — all shaped by real user feedback.

**Tech:** Swift · SpriteKit · Xcode · GameKit · UserDefaults

-----

### 📚 Onboarding Curriculum (Amazon)

Designed and delivered onboarding and continuous learning programs using the ADDIE instructional design framework. Leveraged LMS platforms to track learner progress and improve training effectiveness.

**Skills:** Instructional Design · ADDIE · LMS Administration · Facilitation

-----

### 🏀 PeacePlayers Detroit

Volunteer contributor to PeacePlayers Detroit — an organization using basketball to bridge divides and build community among Detroit youth.
